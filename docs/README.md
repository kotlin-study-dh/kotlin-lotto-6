### Inputs

- Read lotto price to buy
  - must be a multiple of 1000
- Read winning numbers
  - must not be duplicated
  - must be separated by comma(`,`)
- Read a bonus number
- For any invalid input,
  - exception must be thrown with its error message printed
  - it must be possible for users to retry the input

### Outputs

- Print the amount number of lotteries bought
- Print numbers for each lotto
- Print win counts for each ranking
- Print the rate of return

### Calculation

- Prize money
  - Rate of return - rounded to one decimal point
- Number matches
